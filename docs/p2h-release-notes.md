# P2-H 智能面部五区专项祛皱与去油光 (Smart Facial Zonal Wrinkle Smoothing & Anti-Shine Matte) 发布说明

## 1. 概述 (Overview)

在商业摄影修图（婚纱影楼、商务肖像、高级形象照）中，面部特定的衰老暗影与皮脂油光（眼袋膨出阴影、黑眼圈色素、法令纹深凹、额头抬头纹/眉间川字纹、双下巴颈颌阴影、T区高光油光）是影楼修图师最耗时且要求最高的局部工序。传统的全局磨皮往往导致面部失去立体感变成“塑料假面”，或者无法有效抚平局部凹陷阴影。

**P2-H** 引入了**智能面部五区专项祛皱与去油光引擎 (`FacialZonalRefinementEngine`)**：
- **纯原生、离线、零外部 AI 模型依赖**：基于 Vision 框架面部关键点几何拓扑与 GPU 加速 Core Image 自定义核函数 (`CIColorKernel`)；
- **五大面部解剖学专项区域精准平抚**：
  1. **黑眼圈暗沉提亮与色素中和 (`darkCircles`)**：下眼睑月牙形区域微提亮与冷紫/青黑色素向面部健康基底锚点色彩适度暖化；
  2. **眼袋浮肿与眼眶槽阴影平抚 (`eyeBags`)**：沿下眶缘解剖弧线定向填充泪沟凹陷阴影与软化下缘边界；
  3. **法令纹/鼻唇沟平抚 (`nasolabialFolds`)**：精准锚定鼻翼基底至口角外侧弧形走形，自适应软化阴影深度，保留动态自然表情；
  4. **额头抬头纹与眉间川字纹平抚 (`foreheadWrinkles`)**：额中区横向纹理廊道与眉间印堂纵向皱眉纹联合定向虚化平抑；
  5. **T区与面颊油光哑光雾化 (`antiShine`)**：检测额头与鼻梁镜面反射高光白斑 ($L > 0.85$)，柔性压缩至漫反射基调并呈现高级哑光绒雾感；
  6. **双下巴与颈颌线收敛雕刻 (`jawlineSculpting`)**：下颌骨边缘及颏下暗影虚化提亮，收敛双下巴视觉膨胀，凸显紧致下颌轮廓；
  7. **高频微孔肤质保真重注入 (`texturePreservation`)**：默认 70% 真实微孔高频细节保留，彻底杜绝塑料橡皮擦质感。
- **配方版本门禁升级**：Recipe Version 17，完全向后兼容 v1~v16 配方。中性参数零开销（100% 像素直通）。

## 2. 核心架构与技术实现 (Architecture & Implementation)

### 2.1 解剖学关键点与动态蒙版走形 (Anatomical Landmarks & Masks)

| 区域 | 几何构造逻辑 | 蒙版生成方式 |
| :--- | :--- | :--- |
| **黑眼圈 (Dark Circles)** | 眼下月牙形区域：下眼睑轮廓点向下偏移至眶下缘 | 左右眼对称羽化椭圆/多边形蒙版，中和青紫暗沉 |
| **眼袋 (Eye Bags)** | 沿下眶骨下缘形成的半弧形沟槽 | 泪沟走形弧线定向羽化蒙版，专项提亮阴影陷落区 |
| **法令纹 (Nasolabial Folds)** | 鼻翼点到嘴角外下方的两条斜向放射带 | 左右双侧定向带状衰减蒙版，软化嘴角笑纹 |
| **抬头纹 / 川字纹 (Forehead & Frown)** | 眉上额骨横向走形 + 两眉之间印堂纵向走形 | 额头横条与眉心矩形联合蒙版，抚平动态横竖褶皱 |
| **双下巴 / 下颌缘 (Jawline Sculpting)** | 颏下暗影区（下巴轮廓线下方向颈部延伸） | 下颌底部椭圆扩散羽化蒙版，提升下颌线条清晰度 |
| **油光哑光 (Anti-Shine Matte)** | 额中、鼻梁、鼻头及双颊内侧高光热点 | 结合额鼻解剖掩码与亮度高光阈值提取镜面油光并哑光化 |

### 2.2 GPU 加速核心算法 (`CIColorKernel`)

- **健康肤色锚点采样 (`sampleFaceAnchor`)**：自动在面颊中区采样漫反射基准肤色（色相、饱和度、漫反射亮度）；
- **阴影提亮与色相中和**：
  $$\text{targetColor} = \text{anchor} \times \text{diffuseRatio} + \text{localColor} \times (1 - \text{diffuseRatio})$$
  针对黑眼圈微调色相偏向暖色，提升下眼睑活力；
- **镜面油光压缩**：
  对超过阈值的高反光区实施非线性色调压制：
  $$\text{matteLum} = L - (L - L_{\text{threshold}}) \times \text{antiShine} \times 0.65$$
- **高频肤质重注入**：
  从原图提取带通高频微孔纹理 $\text{high} = C_{\text{orig}} - C_{\text{blur}}$，在平抚和去油光后按 `texturePreservation` 权重重叠回图层，保持毛孔与皮肤真实肌理。

## 3. UI 交互设计 (UI & Workflow)

在“人像精修”面板新增【面部专项平抚与去油光】分组：
- 启用/停用总开关
- **黑眼圈消除 (Dark Circles)**：`0.0 ~ 1.0`（默认 0.0）
- **眼袋平抚 (Eye Bags)**：`0.0 ~ 1.0`（默认 0.0）
- **法令纹平抚 (Nasolabial Folds)**：`0.0 ~ 1.0`（默认 0.0）
- **额纹与川字纹 (Forehead Lines)**：`0.0 ~ 1.0`（默认 0.0）
- **面部去油光 (Anti-Shine Matte)**：`0.0 ~ 1.0`（默认 0.0）
- **双下巴轮廓收敛 (Jawline Sculpting)**：`0.0 ~ 1.0`（默认 0.0）
- **微孔肤质保留 (Texture Preservation)**：`0.0 ~ 1.0`（默认 0.70）
- **重置为默认值按钮**

## 4. 兼容性与版本控制 (Compatibility & Versioning)

- **Recipe 规范**：升级至 Version 17。
- **向下兼容**：Version 1~16 配方在加载时自动解码 `facialZonal = nil`，保持 100% 历史视觉输出一致性。
- **导出/验证**：当 `facialZonal` 启用且任一平抚强度非零时，配方版本自动升级至 17。未配置或处于中性默认值时，不强制升至 17。
