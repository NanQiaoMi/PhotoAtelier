### 8.7 一体化选版工作流（影楼全流程）

官方帮助文档描述的完整链路（A 级）：

1. **拍摄/质检**：门店摄影师用像素芝士企业账号联机拍摄（支持有线与 FTP 无线），边拍边传至像素蛋糕；质检师在芝士 Web 工作台或蛋糕「选片交付」实时查看并推送提醒；
2. **初修**：修图师在蛋糕云空间企业空间进入项目，导出时勾选「上传云端」并选「初修图」；（可选）绑定 ERP 并勾选「同步至 ERP 订单」；
3. **排版**：设计师在像素苏打导入云项目 → 版面设计 → 导出选版文件/电子相册 → 上传云空间；
4. **选版**：选版师在像素曲奇导入云项目选版，结果同步回蛋糕/苏打；
5. **精修替版**：数码师在蛋糕筛「已选版/未选/入册/备注」照片精修 → 导出「精修图」→ 苏打「选版完成」后替版；
6. **交付**：通过像素芝士小程序在线选片/交付。

角色分工、云空间 + NAS 双链路、宣称「最快当日成片交付」。来源：[帮助·选版工作流](https://www.pixcakeai.com/guide/166799)；[官方首页](https://www.pixcakeai.com/) 工作流段落。
