# P2-E 功能交付说明：联机拍摄热文件夹实时监视与自动调色 (Tethered Watch Folder & Auto-Apply)

## 1. 功能概述

在商业摄影棚、肖像写真、电商静物及广告拍摄中，摄影师通常使用相机原厂软件（如 Sony Imaging Edge、Canon EOS Utility、Nikon NX Tether、Fujifilm X Acquire 或 Capture One）通过 USB Type-C 连线将相机快门触发的照片实时写入计算机本地指定文件夹。
**P2-E 联机拍摄热文件夹实时监视与自动调色** 为光屿（PhotoAtelier）提供了无需任何外部网络或第三方中间件的本地原生热文件夹监视与即时调色预览引擎：
1. **系统级事件实时监视 (`TetheredWatchManager`)**：基于 macOS 原生 `DispatchSourceFileSystemObject` 监听目录系统事件，毫秒级感知新照片写入。
2. **渐进式写入平稳判定 (`File Stability Settle Check`)**：针对大尺寸 RAW / 高清 JPEG 文件的流式写入特性，结合文件大小稳定性与修改时间窗口判定，避免相机尚未完成磁盘写入时因过早读取导致的半截或损坏文件问题。
3. **即时自动调色与主屏预览 (`Auto-Apply & Instant Preview`)**：新照片落盘后自动无缝接入左侧胶卷胶片列表，自动应用当前活跃配方（色彩空间、基础曝光、胶片 LUT、局部蒙版、人像精修等），并可配置自动全屏选中最新照片，供摄影师与客户在大屏即时审片。
4. **灵活监视配置**：支持递归子目录扫描（针对按日期或卡槽自动建子目录的联机工具）、平稳延时微调（0.2s ~ 2.0s）、手动即时扫描与状态控制。

## 2. 核心技术规格

### 2.1 架构设计
- **底层监听**：使用 POSIX `open(O_EVTONLY)` 打开目录描述符，构建 `DispatchSource.makeFileSystemObjectSource` 监听目录写、增、属性变更事件，配合 `DispatchSourceTimer` 定时检查双重保险。
- **平稳状态机**：
  - 忽略 0 字节正在分配中的文件；
  - 跟踪每个新文件的字节尺寸，保证在配置的 `fileStabilityDelay` 时间窗口内文件大小完全稳定无增长后再发布 `onNewPhotos`。
  - 自动排除非支持的非照片文件、临时隐藏文件（`.DS_Store`、`.tmp` 等）。
- **去重与已知库管理**：
  - 启动监视时自动记录热文件夹内既有存量照片，避免启动瞬间重复触发；
  - 接入 `PhotoSelection.merge` 与统一资产属性维护机制。

### 2.2 性能与系统开销
- 零外部网络依赖，完全运行于离线私密沙箱内；
- 监视队列独立调度（`com.atelier.tethered-watch`），空闲状态 CPU 占用接近 0%；
- 内存开销仅保留路径集合索引，无像素级堆积。

## 3. UI 交互体验

1. **顶部工具栏**：
   - 新增「联机拍摄」工具按钮，监视中状态呈现高亮并带有绿色活跃指示点（「联机中」）。
2. **左侧资料库面板**：
   - 文件夹标题旁实时显示联机状态徽标。
3. **独立联机拍摄设置面板 (`TetheredWatchSheet`)**：
   - **监视状态指示器**：运行中（绿色）、已暂停（黄色）、未监视（灰色）、错误（红色）。
   - **文件夹选取**：系统标准目录选择器，支持在访达中一键打开定位。
   - **自动全屏呈现最新照片**：拍摄一张即刻呈现最终效果。
   - **监视子文件夹**：方便多卡槽或分批子目录结构。
   - **写入平稳等待时间滑杆**：0.2 秒至 2.0 秒无级微调。
   - **工作流指引**：清晰说明 Sony、Canon、Nikon 等联机工具与光屿的无缝配合方式。
