# 真实照片审美验收体系规范 (Aesthetic Review System Specification)

> 版本: v1.0 (2026-11-05)  
> 适用阶段: P1-H 审美验收与后续各功能画质交付

---

## 1. 原则与底线

1. **合成测试与画质审美验收严格解耦**:
   - 自动化单元测试（`swift test`）基于合成标定图与数学边界，用于保障算法数值稳定性、无 NaN/溢出、单调性与无回归；
   - **绝不把合成测试的“全绿通过”等同于真实相机的画质与审美合格**；真实照片的审美交付必须由人工评审表背书。
2. **样片安全与隐私底线**:
   - **样片绝不入库**: 真实样片为外部授权资产，严禁直接 `git add` 提交到代码版本库；
   - **零篡改保证**: 样片在处理前后必须通过 SHA-256 校验，严禁对输入原图进行就地重写或覆盖；
   - **输出匿名化**: 评测输出与报告仅使用规范化代号（如 `sample-portrait-01`），绝不泄漏客户/摄影师真实文件名、原图绝对路径、EXIF 序列号与 GPS 位置。

## 2. 样片集规范与 6 大题材矩阵 (Corpus Taxonomy)

标准审美验收样片集要求覆盖主流摄影创作与影楼客片的 6 大核心题材（建议规模 20–30 张，标准样片集为 24 张）：

| 题材分类 | 样片代号 | 核心视觉特征 | 重点考核功能管线 | 审美关注焦点 |
|---|---|---|---|---|
| **人像·特写** (Portrait Close-up) | `sample-portrait-01` ~ `04` | 单人面部特写、清晰五官、室内柔光/自然光 | 人像精修、妆容塑颜、面部液化 | 毛孔发丝保留、牙齿眼白自然提亮、唇色眼影边缘贴合 |
| **人像·环境** (Portrait Environment) | `sample-portrait-05` ~ `08` | 户外半身/全身、复杂背景、双人或多人 | 自动场景、肤色统一、景深光影 | 多人脸识别与独立修饰、背景光影协调、发丝与背景分离 |
| **风光·自然** (Landscape Nature) | `sample-landscape-01` ~ `04` | 蓝天白云、山川树林、丰富色相细节 | 场景自适应、五区 EV、色彩分级 | 蓝天过渡无色彩断层、绿植不假艳、阴影暗部通透度 |
| **夜景·高反差** (Night Scene) | `sample-night-01` ~ `04` | 城市夜景、霓虹灯、高反差光源与大暗部 | 曝光保护、噪点控制、胶片质感 | 高光光斑不溢出、暗部噪点抑制且不糊成色块、黑位纯净 |
| **逆光·大光比** (Backlight Dynamic) | `sample-backlight-01` ~ `04` | 强夕阳逆光、发丝边缘金光、主体欠曝 | 局部曝光建议、高光辉光、五区调光 | 亮部不过曝爆死、面部欠曝平滑提亮、逆光光晕柔和 |
| **高调与暗调** (High-Key / Low-Key) | `sample-tonal-01` ~ `04` | 影棚纯白背景/留白 (High-Key) 与极简暗黑质感 (Low-Key) | 单调五区曲线、SDR边界映射、质感滤镜 | 高调留白有层次不刺眼、暗调纯黑不死黑且细节可辨 |

## 3. 五维量化评分体系 (Scoring Rubric)

每张真实照片在应用各功能管线后，由专业评审人员基于 5 大维度进行量化打分（每项 1–5 分，总分 25 分）：

```
┌─────────────────────────────────────────────────────────────┐
│                 5-Dimension Scoring Rubric                  │
│                                                             │
│  [1] 微观质感与毛孔保留 (Skin Texture & Micro-details)      │
│  [2] 色彩还原与色调协调 (Color Fidelity & Harmony)          │
│  [3] 高光暗部过渡与动态 (Dynamic Range & Tonal Gradation)   │
│  [4] 几何形变与边缘完整 (Geometry & Edge Integrity)         │
│  [5] 商业成片直接交付度 (Commercial Delivery Readiness)     │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 详细评分细则

#### 维度 1: 微观质感与毛孔保留 (Skin Texture & Micro-details)
- **5分 (卓越)**: 皮肤毛孔、睫毛、发丝与衣物纤维 100% 真实保留；光影过渡平整细腻，无任何涂抹或塑料假面感。
- **4分 (良好)**: 主要肌理纹理完整，仅轻度细微噪点被平滑，整体观感自然高级。
- **3分 (合格)**: 局部较粗糙瑕疵被抹平，轻度平滑感，但未破坏五官核心结构。
- **2分 (欠佳)**: 出现明显塑料假面感、毛孔模糊缺失或磨皮伪影。
- **1分 (严重不合格)**: 面部糊成大片平涂色块，五官边缘模糊或结构失真。

#### 维度 2: 色彩还原与色调协调 (Color Fidelity & Harmony)
- **5分 (卓越)**: 肤色健康通透（红润透亮、黄微暖金），环境色调和谐高雅；无任何不自然杂色染色或色相断层。
- **4分 (良好)**: 风格化调色精准，整体色调悦目，肤色保护良好无突兀偏移。
- **3分 (合格)**: 色彩表现正常，轻微饱和度偏高或局部偏中性，整体在可接受范围。
- **2分 (欠佳)**: 肤色发青、发灰或蜡黄；局部出现明显色带断层（Color Banding）或色相溢出。
- **1分 (严重不合格)**: 严重偏色、LUT 域外畸变或通道剧烈剪切失真。

#### 维度 3: 高光与暗部过渡 (Dynamic Range & Tonal Gradation)
- **5分 (卓越)**: 高光极亮处渐进收敛无硬边截断，暗部沉稳不死黑；五区曲线连续单调，影调层次丰富通透。
- **4分 (良好)**: 动态范围过渡自然，除极微小镜面反光外无大面积死白死黑。
- **3分 (合格)**: 明暗反差适中，边缘平滑，保留了主流观感所需的层次。
- **2分 (欠佳)**: 高光区域出现生硬死白边缘，或阴影大面积沉底糊黑。
- **1分 (严重不合格)**: 大面积爆光或暗部塌陷，直方图断崖式剪切。

#### 维度 4: 几何形变与边缘自然度 (Geometry & Edge Integrity)
- **5分 (卓越)**: 面部微调与液化比例协调真实；背景直线门窗无任何扭曲扰动；抠图与画笔边缘毫无生硬毛刺或白边。
- **4分 (良好)**: 人物轮廓修饰自然，背景轻微扰动但处于视线焦点之外，不影响成片。
- **3分 (合格)**: 边缘过渡平顺，形变微弱可察，但主体结构端正。
- **2分 (欠佳)**: 背景直线出现可辨弯曲，或人物轮廓出现羽化发虚、锯齿毛刺。
- **1分 (严重不合格)**: 画面空间严重扭曲变异，抠图残缺脱节。

#### 维度 5: 商业成片交付度 (Commercial Delivery Readiness)
- **5分 (卓越)**: 达到商业杂志封面、高端摄影工作室直接原片精修交付水准。
- **4分 (良好)**: 达到高质量独立摄影客片交付标准，客户满意度高，无需人工额外重修。
- **3分 (合格)**: 达到普通生活照/社媒分享交付标准；商业交付可能需要摄影师补充微调。
- **2分 (欠佳)**: 无法直接交付，存在明显修图痕迹，需退回重做。
- **1分 (废片)**: 严重毁图，不可用。

## 4. 评审记录模板 (Review Scorecard Template)

每轮评审按以下标准表格归档于对应交付说明中：

```markdown
### 真实照片审美评审记录 (样片 ID: sample-XX)
- **题材类别**: [人像 / 风光 / 夜景 / 逆光 / 高调 / 暗调]
- **测试管线**: [Scene_Adaptive / Portrait_Enhance / Makeup_Retouch / Film_Style / Full_Pipeline]
- **输入原图校验**: `sha256: [hash]` (Verified Unchanged)
- **评分明细**:
  1. 微观质感与毛孔: [1-5] 分
  2. 色彩还原与协调: [1-5] 分
  3. 高光暗部过渡: [1-5] 分
  4. 几何形变与边缘: [1-5] 分
  5. 商业交付就绪度: [1-5] 分
- **总评得分**: [XX] / 25 分 (评级: [A+ (≥23) / A (≥20) / B (≥16) / C (<16)])
- **评审结论与意见**: [详细评语，记录优点与后续算法迭代建议]
```

## 5. 自动化评测执行命令

通过专用评测工具一键生成前后对比套图、1:1 细节微观视窗切片与交互式 HTML 评审看板：

```bash
# 编译并运行审美评测流水线
swift Scripts/evaluate_aesthetic.swift "/Users/mimi/Desktop/图片" "artifacts/aesthetic-review"

# 打开交互式审美评审相册
open "artifacts/aesthetic-review/index.html"
```
