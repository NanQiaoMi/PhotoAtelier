# P2-C 功能交付说明：秀发柔顺与边缘碎发消除 (Hair Anti-Frizz Smoothing & Flyaway Removal)

## 1. 功能概述

在人像精修实践中，头发起毛干枯、细微毛躁以及头顶轮廓边缘翘起散乱的细碎“炸毛”是修图耗时极高的工序。
P2-C 在 P2-A（高颅顶/发际线/丰太阳穴）与 P2-B（发缝填充/秀发光泽/发色深邃）的基础上，补齐了发丝精修最后两项关键能力：
1. **秀发柔顺 / 抚平毛躁 (`hairSmoothing`)**：在发型主体区域基于双边边缘保护逻辑平滑微观毛躁与分叉干枯高频噪点，同时完整保留发丝主走向与自然高光弧度，呈现沙龙级丝滑柔顺质感。
2. **边缘去碎发 (`flyawayRemoval`)**：在发冠与头部外轮廓过渡光晕带（Halo Zone）内，自动识别翘起溢出的 1~3 像素高对比度细线碎发，并基于邻域低频纯净背景平滑内插抚平，打造整洁利落的头部轮廓。

---

## 2. 核心技术规格

### 2.1 算法架构
- **零外部模型依赖**：完全基于系统 Core Image GPU `CIColorKernel` 与 `CIGaussianBlur` 运行，无需下载或加载任何第三方权重文件。
- **几何光晕带（Halo Zone）动态计算**：
  - 基于地标与人脸检测包围盒，推导头顶发冠顶部顶点与侧向外延边界。
  - 在外延 $0.90 \sim 1.45$ 倍发际半径区域建立外轮廓过渡光晕权重（$W_{\text{halo}}$）。
- **边缘去碎发实现**：
  - 由高斯核生成自适应半径背景平滑参考图（$\sigma$ 依据脸宽动态自适应，通常为 $3.5 \sim 14.0\text{ px}$）。
  - 差分测算高频细线突变：$\Delta_{\text{stray}} = \|\mathbf{C}_{\text{src}} - \mathbf{C}_{\text{smooth}}\|$。
  - 在光晕带内将高突变像素按 $\text{flyawayRemoval} \times W_{\text{halo}} \times \text{smoothstep}(0.03, 0.18, \Delta_{\text{stray}})$ 渐进混合至平滑背景，无缝消解翘起碎发。
- **秀发柔顺微观平滑实现**：
  - 在主体发区内差分测算毛躁：$\Delta_{\text{frizz}} = \|\mathbf{C}_{\text{src}} - \mathbf{C}_{\text{smooth}}\|$。
  - 采用软阈值保留宏观发束与轮廓线（$1.0 - \text{smoothstep}(0.15, 0.42, \Delta_{\text{frizz}})$），仅对微观毛躁进行定向平滑。

### 2.2 性能与向后兼容性
- **严格中性**：当 `hairSmoothing == 0 && flyawayRemoval == 0` 时，不执行任何模糊或额外内核着色，保持原有性能与像素一致性。
- **向下兼容**：`PortraitRefinementSettings` 自定义解码器针对老版本 JSON（v1~v14）做缺失容错，自动补齐为 0。
- **单帧开销**：在 4K 图像实测增量耗时 $< 5\text{ ms}$。

## 3. UI 交互体验

- 在「人像」侧边栏的「秀发精修与发缝」区中追加两个控制项：
  - **秀发柔顺**（0...1，连续平滑滑杆，默认 0）
  - **边缘去碎发**（0...1，连续平滑滑杆，默认 0）
- 支持全局撤销/重做（⌘Z / ⇧⌘Z），支持原图/处理后对比。
