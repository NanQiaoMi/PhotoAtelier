# P2-F 功能交付说明：智能衣物平整与祛皱 (Smart Clothing Wrinkle Smoothing & Crease Removal)

## 1. 功能概述

在影棚人像、商务写真、证件照与时尚大片拍摄中，被摄人物的衣物（正装衬衫、西服外套、连衣裙、针织衫等）经常因折叠收纳、坐姿挤压或运输产生明显的折痕、压痕与不平整褶皱。传统的修补或仿制画笔需要逐笔涂抹，耗时耗力且容易产生涂抹糊斑与假面塑料感。

**P2-F 智能衣物平整与祛皱** 为光屿（PhotoAtelier）提供了纯原生、端侧离线的 GPU 级面料平整与纹理重构能力：
1. **智能衣物区域隔离 (`Clothing Segmentation Isolation`)**：
   - 基于 Vision 全局人物抠图结果，自动排除头部、发型及面部特征区域；
   - 结合肤色自适应色度门禁，智能避开裸露颈部、胸前及手臂皮肤，精确限定在纺织面料区域。
2. **多频织物重构与去皱 (`Multi-Frequency Fabric Reconstruction`)**：
   - **低频保形 (`Drape Preservation`)**：提取大尺寸自适应高斯基底，保留躯干与衣物大面积 3D 轮廓及主光影走势，杜绝将立体衣物压平；
   - **中频平整 (`Wrinkle Smoothing`)**：平滑大面积散乱折痕与散漫褶皱，使面料平整贴合；
   - **褶皱抑制 (`Crease Removal`)**：针对尖锐折痕、压褶线与深色折印进行定向衰减；
   - **微观编织纹理保护 (`Texture Preservation`)**：提取高频纺织微观纹理（棉麻纤维、毛呢纹理、针织线圈），在去皱的同时可控回填，保持面料真实质感，避免塑料光洁假面。
3. **严格中性与版本向后兼容**：
   - 关闭开关或强度为 0 时零改动；
   - 配方版本升级至 Version 15，向下无缝兼容 v1~v14 旧配方。

## 2. 核心技术规格

### 2.1 算法架构
- **零外部大模型依赖**：完全基于 macOS 内置 Vision 人物分割与 Core Image GPU `CIColorKernel` 并发执行。
- **面部与皮肤绝对保护**：
  - 基于人脸地标推导羽化椭圆头部/发型蒙版（`headMask`），头部区域权重置 0；
  - 基于线性 sRGB 暖色与亮度特征构建皮肤保护门禁，裸露皮肤区域权重置 0。
- **自适应滤波尺度**：
  - 低频基底尺度 $\sigma_{\text{base}} \approx 8.0 \sim 36.0\text{ px}$（随画布短边自适应）；
  - 中频滤波尺度 $\sigma_{\text{mid}} \approx 2.0 \sim 10.0\text{ px}$；
  - 微观纹理差分 $T_{\text{micro}} = I - I_{\text{mid}}$。
- **GPU 渲染性能**：4K 高清图单次增量执行耗时 $< 8\text{ ms}$。

### 2.2 接口与数据结构
- `ClothingRefinementSettings`：
  - `enabled: Bool`
  - `wrinkleSmoothing: Double` (0...1)
  - `creaseRemoval: Double` (0...1)
  - `texturePreservation: Double` (0...1, default 0.7)
- `ClothingRefinementReport`：记录应用状态与处理阶段。
