## 1. 概述与背景

在前期交付中，Photo Atelier 建立了覆盖格式导入、人像修复、调色曲线、液化美型、证件照换背景、AI 挑图、增强妆容以及 24MP 全画幅性能基准等一系列完整功能。然而，正如技术路线图与团队守则所强调：
> **「自动化单元测试保障算法单调性与无越界；绝不能把合成测试的“全绿通过”等同于真实相机的画质与审美合格。」**

**P1-H** 确立了面向真实摄影作品的**真实照片审美验收体系**，实现画质审美与工程测试的彻底解耦与规范化交付。

## 2. 核心交付组件

### 2.1 审美验收规范与 5 维量化标准 (`docs/aesthetic-review-system.md`)
- **6 大题材矩阵分类**:
  1. 人像·特写 (`portrait-closeup`)
  2. 人像·环境 (`portrait-environment` / `portrait-group`)
  3. 风光·自然 (`landscape`)
  4. 夜景·高反差 (`night-scene`)
  5. 逆光·大光比 (`backlight`)
  6. 高调与暗调 (`high-key` / `low-key`)
- **5 维量化评分标准 (1–5 分制，总分 25 分)**:
  1. 微观质感与毛孔保留 (Skin Texture & Micro-details)
  2. 色彩还原与色调协调 (Color Fidelity & Harmony)
  3. 高光与暗部过渡平滑度 (Dynamic Range & Tonal Gradation)
  4. 几何形变与边缘自然度 (Geometry & Edge Integrity)
  5. 商业成片交付度 (Commercial Delivery Readiness)
- **严格隐私与安全底线**:
  - 样片外部只读引用，绝不入库 Git；
  - 样片处理前后进行 SHA-256 哈希比对，保障原图零改动；
  - 评测输出使用规范匿名代号（`sample-01` ~ `sample-13`），屏蔽客户真实元数据与文件路径。

### 2.2 自动化审美评测执行器 (`Scripts/evaluate_aesthetic.swift`)
- 编译生成原生工具 `build/evaluate_aesthetic`。
- 对样片批量自动执行 6 大核心方案管线：
  1. `01_baseline`: 原始解码基线
  2. `02_scene_adaptive`: 启发式场景自适应与五区调光
  3. `03_portrait_retouch`: 祛斑 + 中性灰高低频平整 + 牙齿眼白提亮 + 肤色统一
  4. `04_makeup_sculpt`: 唇/眉/腮红/眼影/眼线/睫毛/高光/修容精修妆容
  5. `05_film_style`: 富士经典 Classic Chrome 色彩风格与自适应肤色保护
  6. `06_master_pipeline`: 场景校正 + 人像双频精修 + 妆容塑颜 + 胶片影调完整组合
- 自动渲染输出：
  - 1600px 高保真预览 JPEG（用于快速横向对比）；
  - 512×512 1:1 像素级微观切片（针对面部五官、眼周睫毛、毛孔纹理、发丝高光边界）；
  - 交互式 HTML 评审相册 (`artifacts/aesthetic-review/index.html`)，内建 Before/After 实时滑动对比滑杆、微观 1:1 放大视窗、星级评分录入及导出功能；
  - 机器可读的 `aesthetic-manifest.json`。
