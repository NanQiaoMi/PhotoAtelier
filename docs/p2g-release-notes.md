## 1. 概述与核心价值

在商业影棚写真、婚纱人像、形象照与证件照中，人物面部精修与发型美化已日臻完善。但在全身或半身人像中，脖颈横纹、手背青筋、关节暗沉及身体与面部肤色脱节等问题经常削弱整体画质。

**P2-G 智能身体与手部美肤精修** 为光屿（PhotoAtelier）提供了纯原生、端侧离线的 GPU 级身体美肤引擎：
- **颈部平整与颈纹淡化 (`neckSmoothing`)**：定位下颌骨至锁骨之间的颈部走廊，频域滤波消除横向折痕阴影；
- **手部中性灰与青筋淡化 (`veinReduction`)**：识别四肢与手部青蓝冷调静脉突起，保形平滑与色度过渡，消除青筋凸起与关节暗沉；
- **身体中性灰磨皮 (`bodySmoothing`)**：针对锁骨、肩膀、手臂、双腿裸露皮肤进行多频中性灰磨皮，抚平粗糙毛孔；
- **微观真皮肌理保护 (`texturePreservation`)**：高频毛孔残差保真（默认 70%），保留真实皮肤细节，拒绝塑料假人感；
- **身体与面部肤色统一 (`bodyToneHarmonization`)**：采样面部健康肤色锚点，协调身体与面部的色温明度平衡；
- **五官与头发严格隔离**：基于 Vision 人脸轮廓与地标构建羽化遮罩，面部五官（眼、眉、唇、鼻、妆容）100% 隔离不受身体平滑影响。

## 3. 配方版本与兼容性保证 (Recipe Version 16)

1. **配方升级**：
   - 含有非中性 `bodySkin`（`enabled == true` 且任一强度非零）的配方自动升为 **版本 16**；
   - `Recipe.validateVersion()` 严格校验版本区间 `1...16`，阻止旧版本静默丢弃新功能。
2. **严格向后兼容**：
   - 所有在 v1~v15 保存的历史配方，解码时 `bodySkin` 为 `nil`；
   - 渲染引擎在 `bodySkin == nil || bodySkin.isNeutral` 时直接复用原图指针（`result.image === testImage`），100% 保证历史成片像素绝对无损。
3. **前向防护**：
   - 未知未来版本（v17+）在建输出目录前直接拒绝，防止脏数据入库。
