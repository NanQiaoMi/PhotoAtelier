# P2-D 功能交付说明：影棚纯色背景平整与瑕疵修复 (Studio Backdrop Smoothing & Defect Removal)

## 1. 功能概述

在影棚人像、电商模特、肖像写真与证件照拍摄中，无缝背景纸、幕布或无影墙经常存在折痕、接缝、不均匀光影衰减，以及脚印、灰尘和胶带印等瑕疵。
传统的全图背景替换（抠图贴平色）会丢失真实的地面接触投影与发丝边缘透光，显得塑料且失真。
**P2-D 影棚纯色背景平整与修复** 引入了非破坏性、保留原始画面肌理与接触投影的原生背景精修能力：
1. **背景平整 / 折痕抚平 (`smoothing`)**：智能识别背景区域，自适应平滑背景纸折痕、幕布褶皱、接缝与不均光影，同时严格保护人物主体、发丝边缘及地面自然阴影。
2. **瑕疵去污 / 脏污消除 (`cleanup`)**：自动定位背景上的孤立高对比度脚印、灰尘斑点、胶带残留及污渍，并基于低频纯净背景平滑内插抚平。
3. **色调统一 (`uniformity`)**：中和并统一背景色温偏色，消除边缘环境反光。

---

## 2. 核心技术规格

### 2.1 算法架构
- **零外部大模型依赖**：完全基于系统 Vision 人物分割与 Core Image GPU `CIColorKernel` 并发执行。
- **人物主体严格保护**：
  - 基于 `PersonMatting` 提取高保真人物蒙版并进行安全反相与软边缘侵蚀（`smoothstep(0.15, 0.80, bgWeight)`）。
  - 人物发丝、衣物、皮肤及其半透明羽化过渡边缘权重为 0，绝对不受背景滤波影响。
- **频域亮度差分与着色器**：
  - 动态计算自适应高斯低频参考基底（$\sigma$ 依据画面尺寸自适应，通常为 $6.0 \sim 36.0\text{ px}$）。
  - 利用亮度差分测算折痕与渐变过渡，滤除高频褶皱；
  - 针对高对比度突变瑕疵（脚印、脏点）执行加权内插平复。

### 2.2 性能与向后兼容性
- **严格中性**：`enabled == false` 或各项强度全为 0 时，管线完全不改动任何像素，`isNeutral == true`。
- **向下兼容**：配方支持 v14，旧版配方（v1~v13）反序列化时缺失新字段自动缺省为 `nil`，维持原有渲染路径。
- **单帧开销**：在 4K 图像实测单次增量耗时 $< 6\text{ ms}$。

## 3. UI 交互体验

- 在「证件照 / 背景」面板中新增独立控制区：**影棚纯色背景修复**
  - **启用影棚背景修复开关**（独立于证件照换背景，可单独用于原图修背景）
  - **背景平整滑杆**（0...1，连续百分比）
  - **瑕疵去污滑杆**（0...1，连续百分比）
  - **色调统一滑杆**（0...1，连续百分比）
  - **重置背景修复按钮**
- 全面接入全局撤销/重做（⌘Z / ⇧⌘Z）与状态提示。
